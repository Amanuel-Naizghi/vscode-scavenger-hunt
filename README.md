# 2.What's the difference between Git and GitHub?
- From my understanding git is in your local machine in which you interact with it using command line or terminal while github is a website where your git lives and you can interact with it on the web and do different operations easily.

# 3.Why might a developer choose to make a repository public vs. private?
- If its public it is visible to other users so that they can review your code and collaberate if needed.

# 4.What does "pushing" code mean?
- Pushing code means sending your code that is saved in git to github
